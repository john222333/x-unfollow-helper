三步开始整理关注

  1. 读取关注列表：在 Chrome 里登录 x.com，然后点下面的按钮。插件在后台读取，不会弹出窗口。
  2. 筛选要取关的人：用「不回关」「疑似机器人」「零推文」等标签和搜索框筛选；想保留的人点 ☆ 加入白名单，永远不会被取关。
  3. 加入队列：之后插件按安全节奏在后台自动执行，每天有上限，遇到 X 的限制会自动停下。取错了可以在「日志」里一键重新关注。

在后台读取，不会弹出窗口。你开着 x.com 时插件借用那个页面；没开时会在标签栏最左边放一个固定的小标签页，用完自动关掉。被 X 限制读取频率时会自动等待后接着读。

逐个查看关注对象最近一次发帖（原创、回复、转推都算）的时间，查完就能在下面按「多久没发推」筛选。只读取不取关；按 X 给的额度自动放慢，人多时要几个小时，可以关掉这个页面，查到一半停下也会保存。白名单里的人不查。

热点与推文建议

在浏览器侧边栏看正在升温的 AI / Web3 话题，一键生成推文草稿，填进 X 的发推框后由你自己决定发不发。插件不会替你发推。

在 X 上建一个列表（公开或私密都行），把你认可的 AI 或 Web3 博主加进去，再把列表链接贴到这里。插件借用你开着的 x.com 页面读取列表里的最新推文，按互动增速算热度；最多各 5 个列表。不登记也能用，只是热度来自你刷到的首页推文和下面的外部来源。

推文草稿用的模型

key 只保存在这台电脑的浏览器里，导出数据时也不会带上。生成草稿时，插件把话题标题、相关推文和新闻摘要直接发给你选的服务商，不经过其他服务器；费用由服务商按用量向你收取（用 Claude Haiku 或 DeepSeek，每次生成大约几分钱人民币）。

数据

所有数据只保存在这台电脑的浏览器里。取关和读取列表是在 x.com 页面里调用 X 网页版自己的接口，用的是浏览器已有的登录状态（和你在页面上点按钮发出的请求一样），登录信息不会被保存或发送到别处。取关功能只连接 X 自己的网站和服务器（x.com、存放网页代码的 abs.twimg.com、显示头像用的 pbs.twimg.com）。热点功能另外会读取你在上面勾选的公开新闻源，生成草稿时连接你选的模型服务商，这些网站都要你点「保存」时授权才会访问。插件不收集任何统计数据。卸载插件会删除这里的全部数据。

本插件不是 X 官方产品。自动取关不符合 X 的自动化规则，即使按默认节奏也有被限制的风险，请自行承担。
